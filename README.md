## 🚀 How to Run Locally

### Option 1: Direct Browser Launch (Zero Installation)
Simply double-click `index.html` or open it with Google Chrome / Microsoft Edge.

### Option 2: Local HTTP Server (Recommended)
From this directory, run:
```bash
# Using Node / npx:
npx serve .

# Or using Python:
python -m http.server 8080
```
Then visit: `http://localhost:8080` (or `http://localhost:3000`).

## 🌐 How to Deploy for Free (100% Free Hosting)

### Method A: GitHub Pages (Recommended)
1. Initialize a Git repository and commit your files:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of QA portfolio"
   ```
2. Create a repository on GitHub (e.g. `qa-portfolio` or `karanpratap.github.io`).
3. Push to GitHub:
   ```bash
   git remote add origin https://github.com/<your-github-username>/<repo-name>.git
   git branch -M main
   git push -u origin main
   ```
4. Go to **Repo Settings → Pages → Build and deployment → Branch: main / (root) → Save**.
5. Your portfolio is instantly live worldwide at `https://<your-github-username>.github.io/<repo-name>`!

### Method B: Vercel / Netlify (Drag & Drop)
- Simply drag and drop the `karan-qa-portfolio` folder into the Netlify or Vercel dashboard for an instant `.app` domain with SSL.
