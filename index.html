Core Discipline • Automation

Modular Playwright BDD + Custom World

Built with TypeScript and Cucumber.js, this architecture decouples business logic from execution mechanics. Utilizes Playwright's `APIRequestContext` to inject authentication state, cutting test duration by up to 60%.

✓ Declarative Gherkin: Three Amigos standard for unambiguous acceptance criteria.
✓ Semantic Locators: `getByRole` & `getByTestId` with auto-waiting assertions (no hardcoded sleeps).
✓ Custom Cucumber World: Encapsulates isolated browser contexts, API clients, and trace collectors.
support/custom-world.ts
import { World } from '@cucumber/cucumber';
import { BrowserContext, Page, APIRequestContext } from 'playwright';

export class CustomWorld extends World {
  page!: Page;
  context!: BrowserContext;
  apiClient!: APIRequestContext;

  async initContext(storageState?: string) {
    this.context = await browser.newContext({ storageState });
    this.page = await this.context.newPage();
  }
}

agents/test_repair_graph.py (LangGraph)
from langgraph.graph import StateGraph, END
from typing import TypedDict

class AgentState(TypedDict):
    dom_snapshot: str
    failed_selector: str
    repaired_locator: str
    confidence: float

workflow = StateGraph(AgentState)
workflow.add_node("analyze_dom", dom_analyzer_agent)
workflow.add_node("propose_locator", semantic_locator_agent)
workflow.add_node("verify_selector", playwright_verification_agent)

workflow.set_entry_point("analyze_dom")
workflow.add_edge("analyze_dom", "propose_locator")
workflow.add_edge("propose_locator", "verify_selector")
workflow.add_edge("verify_selector", END)
